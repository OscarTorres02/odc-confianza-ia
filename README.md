# ¿Se puede confiar en la IA?

Objeto Digital de Conocimiento (ODC) · Especialización en Analítica y Ciencia de Datos · Universidad de Cundinamarca.

**Indicadores para evaluar la confianza en modelos de aprendizaje supervisado explicables para decisiones organizacionales.**

- Autores: Oscar Manuel Torres Maldonado · María Lucía Torres Maldonado
- Tutor: Darwin Andrés Díaz Gómez
- 18 pantallas · 8 módulos · 8 miniactividades + evaluación final (100 puntos, se aprueba con 70)

## Cómo verlo
- **En línea:** https://oscartorres02.github.io/odc-confianza-ia/
- **En Moodle u otro LMS:** descargar el paquete SCORM 1.2 desde [Releases](https://github.com/OscarTorres02/odc-confianza-ia/releases/latest) (`odc_confianza_ia_SCORM12.zip`) y subirlo como actividad SCORM sin descomprimir. El ODC reporta estado (passed/failed), puntaje 0–100 y guarda el avance.
- **Sin conexión:** descargar el repositorio y abrir `index.html` en el navegador.
